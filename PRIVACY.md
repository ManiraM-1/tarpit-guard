# Privacy policy

Last updated: 2026-11-28

This policy covers tarpit-guard in every form it ships in: the Python package and CLI, the MCP server, the Claude Desktop extension (`.mcpb`) and the Claude plugin.

## Data collection

tarpit-guard collects no data. It has no accounts, no analytics, no telemetry and no crash reporting.

## Usage and storage

The tools read only the files, folders or text you, or the AI agent you are using, point them at. They measure the shape of that text locally and return a score. They never run, decode or deobfuscate code. Nothing is written to disk and nothing is kept after a check finishes.

## Third-party sharing

tarpit-guard makes no network requests while it runs, so it shares nothing with anyone. Installing it downloads the package and its dependencies from PyPI (pypi.org and files.pythonhosted.org), which is governed by PyPI's own privacy policy. The AI app you use tarpit-guard with (for example Claude) receives the check results, under that app's privacy policy.

## Data retention

None. tarpit-guard stores no data, so there is nothing to retain or delete.
